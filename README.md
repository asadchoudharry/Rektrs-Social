# REKTRS Social Media Assets

Temporary public media hosting for REKTRS social posts.

## Folder convention

Each campaign is stored under a dated folder:

```
YYYY-MM-DD/campaign-name/
```

Example:

```
2026-10-07/connected-system-carousel/
```

Assets older than 7 days are removed automatically by GitHub Actions.

> Do not store confidential, client-sensitive, or private material in this repository.
